# Loci example (FASTA)

Put FASTA files of loci here (`.fasta`, `.fa`, `.fas`, `.fna`): for
example one file per sample with one sequence per locus, as in target
capture. The **Loci example** button of option 1d (step 1) loads them and
opens the Sample and marker dialog; its tooltip is edited in
`../tooltips.json`. Rebuild the app after adding files: assets are bundled
at build time.
