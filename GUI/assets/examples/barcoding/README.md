# Barcoding example (FASTA)

Put FASTA files of DNA barcodes here (`.fasta`, `.fa`, `.fas`): one
specimen per sequence, e.g. COI. The **Barcoding example** button of
option 1d (step 1) loads them with "These sequences are DNA barcodes" on,
ready to identify the specimens and export the BOLD sheet; its tooltip is
edited in `../tooltips.json`. Rebuild the app after adding files: assets
are bundled at build time.
